# 📟 PRAXEO TERMINAL
**Institutional Market Telemetry & Sector Trajectory Analytics**

Praxeo Terminal is an elite, End-of-Day (EOD) quantitative analytics dashboard designed for the Indian Stock Market. Built with a minimalist, retro-cyberpunk aesthetic, it strips away market noise to deliver deep, mathematical insights directly to retail traders. 

Live Preview: https://praxeo-terminal.vercel.app/

---

## ⚡ Core Modules

### 1. Indicator 01: Market Breadth Matrix
A clutter-free telemetry system tracking the underlying strength of the Nifty 50 and 14 sectoral indices.
* **EMA Tracking:** Monitors stocks performing above key Exponential Moving Averages (9, 20, 50, 100, 200).
* **Trend Analysis:** Visualizes 3-month and 6-month structural trends to identify true market momentum.
* **A/D Ratios:** Real-time Advance-Decline metrics for pure price action sentiment.

### 2. Indicator 02: Sector Rotation Matrix (Upcoming)
A gamified Relative Rotation Graph (RRG) logic system that identifies sector shifts before they become mainstream news.
* **Quadrant Tracking:** Leading, Weakening, Lagging, and Improving.
* **Vectra Conviction Score:** A proprietary 1-100 algorithmic score based on trend depth and momentum velocity.
* **Actionable Telemetry:** Generates instant "TL;DR" insights (e.g., *Smart money detected in Auto. Breakout probability high.*)

## 🛠️ Tech Stack
* **Frontend:** React.js, TypeScript, Vite
* **Styling:** Tailwind CSS (Custom Dark/Neon Theme)
* **Data Visualization:** Plotly / Chart.js (For structural charts)
* **Deployment:** Vercel (Serverless Edge Network)
